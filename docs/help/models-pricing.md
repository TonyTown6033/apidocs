# 模型选择与计费说明

平台当前提供 Claude、OpenAI GPT、DeepSeek 和图像模型。完整实时列表请查看[模型与价格](/guide/pricing)。

## 选择建议

- **Claude Code**：选择支持 `anthropic` 端点的模型。
- **Codex 或 OpenAI SDK**：选择支持 `openai` 端点的模型。
- **复杂推理与大型项目**：优先查看带有 `Reasoning`、`Tools` 和较大上下文标签的模型。
- **高频、成本敏感任务**：在模型广场比较输入、输出和缓存价格后再选择。
- **图片生成**：选择图像模型，并确认客户端使用模型支持的端点。

## 什么是缓存

缓存可降低重复上下文的成本：

- 缓存创建可能产生单独费用；
- 后续请求命中缓存时，按缓存读取价格计费；
- 并非所有模型都公开缓存价格或支持相同的缓存策略。

## 什么是上下文

上下文是模型一次请求能够处理的输入范围。模型广场使用 `200K`、`1M`、`1.1M` 等标签标注不同模型的上下文能力。实际限制还可能受到客户端、接口和账户策略影响。

## 核对实际消费

登录控制台后打开“使用日志”，可查看模型、输入/输出 Tokens、缓存命中、分组倍率和最终花费。价格发生变化时，以该页面和[模型广场](https://superelite.studio/pricing)为准。
