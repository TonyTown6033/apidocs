# 注册与充值

创建账号并为账户充值。

## 注册账号

1. 访问官网 [https://superelite.studio/](https://superelite.studio/)
2. 点击右上角注册按钮
3. 填写邮箱和密码完成注册

请使用常用邮箱注册，方便接收通知和找回密码。

## 充值

1. 登录后进入侧边栏的“钱包管理”
2. 在“账户充值”中选择支付方式；官网当前展示支付宝和 Stripe
3. 选择或填写充值额度，确认页面显示的实付金额和优惠
4. 如有兑换码，也可以在“兑换码充值”中兑换额度

钱包页面还会展示当前余额、历史消耗、请求次数、账单和邀请奖励。支付方式、折扣和汇率可能调整，请以提交付款前的页面信息为准。

完成充值后，再继续进行[创建令牌](/guide/token)。
