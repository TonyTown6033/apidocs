# 创建令牌

生成 API Key 用于访问服务。

> 令牌是访问 API 的凭证，请妥善保管，不要泄露给他人。

## 添加令牌

1. 在侧边栏点击“令牌”，然后点击“添加令牌”
2. 根据需要选择合适的令牌分组
3. 创建完成后复制并保存令牌，格式通常为 `sk-xxxxxxxx`

## 分组选择建议

- 需要 Claude Code 时，优先选择支持 Claude 的分组
- 需要 Codex 时，选择支持 OpenAI 兼容接口的分组
- 需要 Gemini CLI 时，选择支持 Gemini 的分组

不同分组支持的模型和价格不同，先对照[价格说明](/guide/pricing)再创建更稳妥。
