# CC-Switch 配置

使用图形化工具管理 API 配置。

CC-Switch 是推荐的配置方式，支持一键切换多个 API 配置。

## 功能特点

- 一键切换 API 配置
- 可视化配置管理
- MCP 服务器管理
- 系统托盘快捷操作

## 下载安装

访问 [CC-Switch 下载页面](https://github.com/) 下载程序，Windows 用户优先选择 `.msi` 安装包。

## 配置 API

1. 安装完成后启动 CC-Switch
2. 点击“添加配置”
3. 填写 API Key 和请求地址 `https://superelite.studio/`
4. 点击“启用”完成配置

使用 CC-Switch 时，通常不需要再手动编辑 Claude 的配置文件。
